## How work scripts

## Curl/Wget downloader

A script that permits you to use wget/curl more quickly by only pasting the url you want.

## Whats my IP

A script that shows you quickly what's your Ethernet and Wifi IP (so 192.168.1.XYZ and 10.0.0.XY).
You have to install `socket` and `psutil` modules before.

## QEFI

A script that permits you to mount your efi partition more quicly.
**You have to run the script as Administrator or with sudo**

## QIPA

A script that can quickly from .app file compress it into an iPA file.
Useful for Xcode developers like me.

## MCVersions

A script that can download quickly minecraft server and client jar onto your pc from [MCVersions.net](https://mcversions.net)
